# GizeGo Mobile App

## Overview

GizeGo is a real-time bus tracking mobile application developed as a final year project. The app helps users find the shortest and most efficient bus route between departure and arrival locations. It also provides real-time bus tracking and notifications about delays, accidents, and other transportation updates.

The application is designed to improve the public transportation experience by making bus navigation easier, faster, and more reliable.



## Features

* User authentication (Login & Signup)
* Real-time bus tracking simulation
* Route and shortest-path bus selection
* Delay and accident notifications
* Interactive map integration
* Bilingual support (Amharic and English)

## Installation and Setup

### Clone the repository

```bash
git clone <repository-url>
```

### Navigate to the project folder

```bash
cd GizeGo
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npx expo start
```



## Available Scripts

```json
"scripts": {
  "start": "expo start",
  "android": "expo start --android",
  "ios": "expo start --ios",
  "web": "expo start --web"
}
```

Run the following commands depending on the platform:

```bash
npm run android
npm run web
```
